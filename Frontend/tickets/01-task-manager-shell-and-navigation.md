# 01: Build the dark task-manager shell and navigation

**What to build:** A user can open the task manager and navigate between Tasks and Create task in a cohesive dark-themed layout. The Tasks view opens by default and, when there are no tasks, offers a clear action to start creating one.

**Blocked by:** None (can start immediately).

**Status:** done

- [x] The app opens on the Tasks view.
- [x] A persistent left navigation panel provides exactly two destinations: Tasks and Create task.
- [x] The selected destination is visually distinguishable and the main content changes when navigation is activated.
- [x] Both navigation choices remain visible and usable at narrow viewport widths.
- [x] The empty Tasks view prompts the user to create the first task and its action opens Create task.
- [x] Navigation uses semantic, keyboard-operable controls with visible focus.
- [x] The dark theme has readable contrast for content, controls, selected navigation, and focus states.
- [x] Browser-level tests verify initial navigation, switching views, the empty state, and narrow-screen navigation through the rendered app.
